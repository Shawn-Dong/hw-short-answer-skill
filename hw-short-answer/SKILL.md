# 作业简答：写法与检查

目标：答案读起来像一个懂这门课的学生自己写的。短，准，有数字，没有套话。学生会读、会改，最后以他自己的名义交。

前提：只在课程允许使用 AI 辅助的作业里用。这个 skill 的设计是学生先给出自己的思路，Claude 负责纠错和落成文字，不是替学生想答案。

## 0. 流程

按互动的方式走：

1. **先补背景**，如果学生要。新概念先给定义和一个小数字例子再用。例子不要直接用题目里的数据，免得把答案说穿。
2. **学生先说思路**，中文英文都行。
3. **纠错**。对的地方明确说对。错的地方说清楚错在哪、为什么错，再引导他改。不要跳过他直接给完整答案，除非他要求。他的答案数学上对、但没回答题目真正想考的点时，也要指出来。比如题目要一个"很烂但 recall 是 1"的系统，他给了一个好系统。
4. **用他的话写成英文**。保留他的论点、例子和用词，只补必要的东西：缺的数字、缺的因果、不准确的术语。
5. **跑检查脚本**，见第 4 节，改到没有 ERROR，WARN 逐条判断。
6. **写进文件**。在对话里用代码块给出英文原文，让他看到写了什么。LaTeX 写完在编辑器里打开让他审，编译只用来查错，不要抢先把 PDF 当成品交给他。
7. notebook 正在后台执行时不要改这个文件。执行器每跑完一个 cell 会把整个文件存一次，你的修改会被覆盖。先把答案存进作业文件夹里的 `pending_answers.md`，跑完再一起填进去。

## 1. 内容：答什么

- **只答题目问的。** 题目说 "one sentence" 就写一句。不复述题目，不铺背景，不加题目没要的定理名或推导，不写总结句。
- **题目指定了用什么解释，就用它。** 比如 "Explain why, using how the weights are computed"，答案里就要出现那条计算过程。
- **用他自己的结果说话。** 数字从 notebook 输出或报告里原样抄，不换算成别的精度。笼统的说法要换成数字，比如 "some models converged faster" 改成 "the linear model only went from 0.412 to 0.409 after epoch 3"。
- **比较要说条件。** 训练步数、参数量、数据不同的比较，要点明不公平在哪。
- **构造例子时，选最能说明题目要点的那个**，通常是极端或退化的情况，而不是一个"还不错"的例子。
- **不确定的不要编。** 没跑过、没算过的数字不要写，先跑或者先问。

## 2. 文风：怎么写

- 短句。平均 20 词以内，单句尽量不超过 30 词。
- 正文里不用括号。数学记号里的括号可以，比如 $P(A\mid B)$、f(x)。想加括号的内容，要么并进句子，要么单独成一句。
- 不用分号，不用破折号。LaTeX 里的 `--` 和 `---` 也算破折号。
- 不写 "A, B, C and D" 式的长枚举句。真实的数据或名字清单可以留。
- 小问标签用 `a.`，不用 `(a)`，除非课程模板规定了别的写法。
- 用简单的词。is、has，不用 serves as、boasts、showcases。
- 句子开头要变化，不要连续三句同一个词开头。
- 结尾停在最后一个具体事实上。不用 Overall、In conclusion、This shows that 收尾。

更完整的 AI 腔清单和修改步骤在 `references/ai-tells-homework.md`。第一次用这个 skill 时通读一遍，之后改稿时对照查。

## 3. 排版

**LaTeX 书面作业**

- 沿用这门课上一份作业的 `.tex` 当模板：页眉放学生姓名和"课程 -- Assignment N"，用一个 `\answer` 宏引出答案，小问用 `enumerate` 加 `label=\alph*.`。
- 一题一页，每个 Problem 前面放 `\clearpage`。
- 如果评分系统，比如 Gradescope，把小问列成单独的评分项，而且答案较长，就按评分项分页，标题用评分系统里的原名。这样标页时一眼就能对上。
- 题目原文抄在答案上面。
- 题目要求但评分系统不单列的结果，放在用到它的那一项下面，用一句短的斜体引出，比如 "Supporting results from Q1a."，不要加括号解释。
- 正文里不用行内 `\tfrac`。

**Notebook 简答**

- 写在题目给的 "Answer: response here" 或 "Response here:" 那个 markdown cell 里，替换掉占位文字，别的 cell 不动。
- 数学写成 `$...$`，美元金额避免裸 `$`，否则会被 MathJax 当成公式。
- 某门课有自己规定的版式时以课程为准，比如要求 `### (x) 标题` 加 `**Answer:**`、代码不写注释。

**AI 使用声明**：课程要求注明 AI 使用时，在末尾放一段简短的 AI use 声明。没要求就不加。

## 4. 检查脚本

```bash
python3 <skill 目录>/scripts/check_answers.py <文件> [<文件> ...]
```

- `.tex`：检查每个 `\answer` 后面的内容，列表按 `\item` 拆开。加 `--all` 改成按 `\clearpage` 分页检查整份文档，标题里的 `--` 会被误报。
- `.ipynb`：检查含 "Answer" 或 "Response" 的 markdown cell，还是占位文字的跳过。
- `.md` 或 `.txt`：每个 `## ` 段落算一个答案，标题含 Notes 的跳过。

**ERROR 必须改。** 括号、分号、破折号、套话、总结句收尾、平均句长超标、超过两个"不是 X 而是 Y"句式。

**WARN 要判断，这几种可以留：**

- `triads`：真实的名字、数据、模型清单。"For example, X, Y and Z" 这种逗号也常被误报。
- `contrast`：否定的那半句在回答题目真正问过的东西。比如题目问 "Does this surprise you?"，答 "This is not surprising." 就该留。
- `ai-words`：在这门课里是标准术语，比如统计里的 robust。

改完再跑一遍。改稿时核对一遍：数字、日期、限定词、引用有没有被改丢。改丢了就是错误，要恢复。
